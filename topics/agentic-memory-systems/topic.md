# Problem statement

Sample topic demonstrating the expected shape. Long-running AI agents accumulate context faster than they can use it. Approaches to persistent memory (vector stores, graph memory, episodic summaries, learned compression) are evolving quickly and coverage is dominated by vendor marketing. I want a grounded view of what actually works, from primary sources and practitioner reports.

# Motivating questions

- Which memory architectures survive contact with multi-week agent deployments?
- What failure modes (stale recall, context poisoning, drift) are reported in practice?
- How do costs scale with memory size across approaches?

# Interested in

- Primary papers and reproducible benchmarks
- Practitioner postmortems and forum threads describing real deployments
- Approaches from outside the mainstream vendor ecosystem, including academic and hobbyist work

# Not interested in

- Vendor product announcements without evaluation data
- General "RAG tutorial" content
- Rehashed listicles of memory frameworks

# Success criteria

A digest each period that surfaces at least one primary source or practitioner report not covered by major AI newsletters.

# Constraints

- English-language sources only for now
- No single task above 21 points without explicit human approval
